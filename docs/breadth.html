Byproduct experiment. Follow-up: does breadth of training buy transfer?

All three surviving theories say intelligence was a byproduct. A faithful simulation therefore scores agents only on staying alive and being copied, then measures general ability separately on held-out tests.

No, by the rule set in advance. With the training budget fixed, the score on 18 task families built on skills the training pool never uses changed by +0.003 for each doubling of the number of families trained on (standard error 0.005). Training at any breadth lifted those families by +0.067 (standard error 0.008) over the untrained model, and more families added nothing further. Pre-set outcome: Flat

Breadth did help one kind of unseen task: families from the same pool that a run happened not to train on. Their gain over the untrained model grew from +0.031 at 2 families to +0.177 at 32 (+0.035 per doubling, standard error 0.005). This comparison was chosen after seeing the data.

Rerun with the rule fixed first: Confirmed. My reading: breadth buys transfer to tasks that resemble the training set, and none to tasks that need a different skill. General ability and the public test stayed flat.

Limits

  • One model size (1.5B). Three runs per level, so each standard error rests on 3 values.
  • At low K, which families were drawn is mixed with how many. Each run drew its own set to average over this.
  • The 52 new pool families and 12 new held-out families were written by AI subagents in one style, then machine-checked. A family that trains a skill close to a held-out one would inflate the curve; the per-family table shows where the gain sits.
  • The first same-pool result was analysed after seeing the data. The rerun fixed its rule first; its outcome is "Confirmed, and the near-far split is confirmed". Two later checks repeated it on a second reserved set and on a 3B model; their outcomes are in the section above. All runs use one model family (Qwen2.5) and one task style.
  • The model was trained on correct answers directly. This measures what breadth can buy at most; it is not a selection experiment.
