Byproduct experiment. Version 4: social arms with changing weights

All three surviving theories say intelligence was a byproduct. A faithful simulation therefore scores agents only on staying alive and being copied, then measures general ability separately on held-out tests.

This version could not test the thesis. Thesis verdict: not testable at this scale

A free check run before any model call showed that the social rules can separate an arm from its control by under one doubling of breadth. Two were needed for a score difference to be detectable with 5 seeds. The verdict was fixed then, before any result.

What the 25 runs did measure. Cooperation: broadens, mechanical (+0.35 doublings of breadth against SOLO, standard error 0.10). Copying from successful non-parents: no breadth change (-0.02 doublings of breadth against SOLO, standard error 0.10).

Populations did learn: SOLO's practised skill ended +0.077 against the untrained 0.510 (standard error 0.014). SOLO minus DRIFT on the same score was +0.001 (standard error 0.022), so by the pre-set rule the learning is credited to the correctness filter.

5 of 5 arms ended above the untrained model on similar unseen tasks (DRIFT, SOLO, SOLO-W, COOP, CULTURE). The largest gain was SOLO at +0.088 (standard error 0.007). SOLO minus DRIFT on that score was +0.041 (standard error 0.021), short of the 2 standard error rule. Part of every gain is reply format: the untrained model gave an unusable reply on 3.7% of these questions, the trained populations on 0.3%. Counting valid replies only, gains run from +0.028 (DRIFT) to +0.068 (SOLO). These lines were added after the smoke test and are exploratory.

Setup: Qwen2.5-1.5B, one adapter per population of 32 agents, 8 generations, 5 seeds per arm. Each agent carries a repertoire of task families and lives 24 one-question rounds. The top 8 by energy are parents. The adapter is trained after every generation on parents' own replies that were correct (SOLO-W: all parent replies). Rules and labels were written before any model call (SPEC4.md).

Limits

  • Who practises what follows repertoire rules written by hand. The null model measures how much of each result those rules explain.
  • One adapter per population. Skill belongs to the population; no claim about an individual can be read from these runs.
  • The learning rule differs from version 3: descendants inherit only what was right. This filter improves a model with no selection.
  • COOP differs from SOLO in three ways at once: two repertoires practised, pay tied to a random partner, parents chosen as pairs.
  • One 1.5B model from one family, 5 seeds, 8 generations, task families written by AI in one style.
  • The code, rules and this page were written by an AI model directed by the author.

Cost: $4.31 for the 25 runs and $0.21 for two smoke runs, $4.52 of an $11 limit (own upper estimate).
